论文导读

问题

I-MCoT 需要决定两件事：当前推理步骤应该看哪块图像区域，以及何时把该区域插入上下文。旧方法常用高注意力区域和换行符等静态触发，容易错过真正证据。

方法

CAG 先生成问题相关的细粒度图像描述以增强文本上下文；DAT 在注意力从文本转向视觉时触发；AVP 用信息增益逐步选择最能降低不确定性的区域。

结论

实验显示 AIM-CoT 在多个 VQA 基准和骨干模型上稳定优于基线。更重要的是，语义命中率和 GPT-4v 盲评表明它选出的视觉证据更完整、更相关。

关键结果

主结果：AIM-CoT 在三个 VQA 基准、四个骨干上稳定领先

论文报告 M3CoT、ScienceQA 使用 Accuracy，LLaVA-W 使用 ROUGE-L。作者强调 AIM-CoT 在 Chameleon-7B、Janus-Pro-7B、Qwen2-VL-7B、Qwen2.5-VL-32B 上均优于 No-CoT、DDCoT、MMCoT、CCoT、SCAFFOLD、ICoT 等基线。

这说明 AIM-CoT 的收益不是某一个模型的偶然适配，而是对多模态推理流程中“证据选择和触发时机”的通用改造。

消融：CAG、AVP、DAT 都有贡献

主文消融在 Chameleon-7B 0-shot 设置下进行。移除任一模块都会损失性能，完整 AIM-CoT 在 M3CoT、ScienceQA、LLaVA-W 上都取得最高结果。

CAG 解决文本-视觉粒度不平衡，AVP 负责选择信息量最大的区域，DAT 负责动态触发。三者不是简单叠加，而是构成前后依赖的流程。

语义命中率 SHR：AIM-CoT 更接近任务相关对象

论文使用 SAM 生成与问题和答案相关实体的分割掩码，并用 IoU>0.5 判断选区是否命中语义对象。ICoT 在 M3CoT、ScienceQA 上分别约为 18.7% 和 24.3%，AIM-CoT 达到约 65.2% 和 71.8%。

这组结果直接支持“信息增益选区比注意力 Top-K 更像人类需要的证据”。它比单纯最终准确率更能解释方法为什么有效。

GPT-4v 盲评：AIM-CoT 选区更符合人类直觉

在 M3CoT 和 LLaVA-W 的 500 个样本上，GPT-4v 盲评 AIM-CoT 的选区优于 ICoT 的比例分别约为 76.4% 和 81.2%。

盲评从相关性、完整性、帮助性三方面评估区域质量。虽然评委模型不是人类标注，但结果与 SHR 一起增强了证据选择质量的可信度。

部署：AVP 有额外开销，但候选规模较小

复杂度主项与 K、候选数 N_C、层数 L、插入区域 token 长度和上下文长度相关。作者认为通过小 K、小候选集、批处理和 KV cache，平均推理时间仍在可部署范围。

这里的现实意义是：AIM-CoT 不是免费提升。它用额外前向计算换更可靠证据，需要根据任务价值和延迟预算决定是否启用。

H2 Abstract

摘要先把论文的核心矛盾讲清楚：交错模态 CoT 的效果取决于选什么视觉证据、什么时候插入视觉证据。AIM-CoT 用 CAG、AVP、DAT 分别处理注意力可靠性、信息量选择和动态触发。

#001

Original

Interleaved-Modal Chain-of-Thought (I-MCoT) advances vision-language reasoning, such as Visual Question Answering (VQA). This paradigm integrates specially selected visual evidence from the input image into the context of Vision-Language Models (VLMs), enabling them to ground their reasoning logic in these details. Accordingly, the efficacy of an I-MCoT framework relies on identifying what to see (evidence selection) and when to see it (triggering of insertions). However, existing methods fall short in both aspects. First, for selection, they rely on attention signals, which are unreliable—particularly under severe granularity imbalance between the brief textual query and the informative image. Second, for triggering, they adopt static triggers, which fail to capture the VLMs' dynamic needs for visual evidence. To this end, we propose a novel I-MCoT framework, Active Information-driven Multi-modal Chain-of-Thought (AIM-CoT), which aims to improve both evidence selection and insertion triggering via: (1) Context-enhanced Attention-map Generation (CAG) to mitigate granularity imbalance via textual context enhancement; (2) Active Visual Probing (AVP) to proactively select the most informative evidence via an information foraging process; and (3) Dynamic Attention-shift Trigger (DAT) to precisely activate insertions when VLM's attention shifts from text to visual context. Experiments across three benchmarks and four backbones demonstrate AIM-CoT's consistent superiority. Our code is available at <https://anonymous.4open.science/r/AIMCoT>.

#006

Original

To overcome these limitations, we propose a novel I-MCoT framework, Active Information-driven Multi-modal Chain-of-Thought (AIM-CoT), which aims to address both what to see and when to see it by shifting VLM reasoning from passive, static perception to active, dynamic exploration. Grounded in Information Foraging Theory , AIM-CoT detects the VLM's momentary need for visual cues and proactively forages for the most informative evidence. Integrated into the context window, this evidence improves subsequent generation. AIM-CoT realizes this shift through three synergistic components: (1) Context-enhanced Attention-map Generation (CAG): To refine the VLM's cross-modal attention distribution, CAG elicits a query-conditioned description of the image and appends it to the textual context. Rather than serving as an auxiliary caption, CAG provides semantic anchors that align textual and visual granularities. (2) Active Visual Probing (AVP): To address the "What to see" problem, AVP quantifies the information gain of candidate regions, integrating those that provide the highest utility into the context for subsequent reasoning and generation. (3) Dynamic Attention-shift Trigger (DAT): To address the "When to see it" problem, DAT dynamically and precisely triggers visual insertion when a significant shift from textual to visual focus is detected, indicating the VLM's cognitive demand for visual evidence.
